### Key Compliance Commitments

1. **No Bundled Articles or Restricted Media**: This repository does **not** bundle or redistribute SCP Wiki articles, translations, or images (including Izumi Kato's *Untitled 2004* sculpture image). All wiki pages are fetched live from the official SCP Wiki (or a user-configured mirror) upon user request.
2. **Attribution Preserved**: Every article rendered in Clean Reader mode or exported to Markdown / HTML retains a direct link to its original SCP Wiki page and a clear CC BY-SA 3.0 attribution notice.
3. **ShareAlike for SCP Derivatives**: Any SCP-derived assets in this repository (such as the application icon inspired by the SCP Foundation emblem) are released under **CC BY-SA 3.0** and may be freely shared and adapted under the same license with attribution.
4. **Source Code Open-Source License**: Original desktop client code (Electron shell, parser, caching engine, UI logic) is open-source under the **MIT License** (see `LICENSE`).
5. **Third-Party Metadata API**: Search, tag filtering, and random discovery optionally query the public SCP community [Crom GraphQL API](https://crom.avn.sh/).
